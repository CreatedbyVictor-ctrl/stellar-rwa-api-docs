# OpenAPI specification

<LastReviewed date={metadata.lastReviewed} />

The v1 surface is described by an OpenAPI 3 document, served by the docs site at
[`/openapi-v1.yaml`](/openapi-v1.yaml). It lists `/`, `/version`, `/health`,
`/metrics` and every route under `/v1`, and can be fed to client generators or
contract-testing tools.

The spec source lives at `docs/public/openapi-v1.yaml` and is linted in CI by the
`OpenAPI` workflow on every change.
