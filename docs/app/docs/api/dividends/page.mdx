# Dividends

<CalloutBox variant="note">
Replace <code>$API_BASE_URL</code> in examples with your configured API base URL (see <a href="/docs/api/overview">API Overview</a>).
</CalloutBox>

<ApiEndpoint method="GET" path="/assets/:id/dividends" description="Distribution history for an asset, newest ledger first." />

Returns every dividend distribution created for the asset's token, ordered by
creation ledger (newest first).

**Path parameters**

| Name | Type | Notes |
|------|------|-------|
| `id` | number | Registry id |

**Response schema** (per distribution):

| Field | Type | Notes |
|-------|------|-------|
| `id` | number | Distribution id |
| `asset_token` | string | The asset paid out on |
| `payment_token` | string | Token used to pay |
| `total_amount` | string | Pool size in **payment-token base units** (`i128` string). Divide by `10 ** payment_token_decimals` to get human-readable units. |
| `distributed` | string | Claimed so far in **payment-token base units** (`i128` string). Divide by `10 ** payment_token_decimals` to get human-readable units. |
| `claimed_percent` | number | Percentage of pool claimed, 0–100 with 2 decimal places (`f64`). |
| `overflow_detected` | boolean | `true` when `distributed` exceeds `total_amount` (on-chain anomaly, not an API bug) |
| `completed` | boolean | `true` once fully claimed |
| `created_at_ledger` | number | |

**Example**

```bash
curl $API_BASE_URL/assets/1/dividends
```

```json
[
  {
    "id": 1,
    "asset_token": "CBMCWLSQSWUTLUJFCNBHNBSXMUM3XU7NAQ5TSNERW4HA4ZZBYHLG4ECZ",
    "payment_token": "CDLZFC3SYJYDZT7K67VZ75HPJVIEUVNIXF47ZG2FB2RMQQVU2HHGCYSC",
    "total_amount": "100000000000",
    "distributed": "25000000000",
    "claimed_percent": 25.0,
    "overflow_detected": false,
    "completed": false,
    "created_at_ledger": 3510000
  }
]
```

An asset with no distributions returns an empty array `[]`.

**Errors**

Returns `404` with `{ "error": "not_found", … }` when the asset id is unknown.

## Get a single distribution

<ApiEndpoint method="GET" path="/assets/:id/distributions/:did" description="A single distribution for an asset, by distribution id." />

**Path parameters**

| Name | Type | Notes |
|------|------|-------|
| `id` | number | Registry id |
| `did` | number | Distribution id |

**Response schema**

Same shape as a single item from the list above.

**Example**

```bash
curl $API_BASE_URL/assets/1/distributions/1
```

```json
{
  "id": 1,
  "asset_token": "CBMCWLSQSWUTLUJFCNBHNBSXMUM3XU7NAQ5TSNERW4HA4ZZBYHLG4ECZ",
  "payment_token": "CDLZFC3SYJYDZT7K67VZ75HPJVIEUVNIXF47ZG2FB2RMQQVU2HHGCYSC",
  "total_amount": "100000000000",
  "distributed": "25000000000",
  "claimed_percent": 25.0,
  "completed": false,
  "created_at_ledger": 3510000
}
```

**Errors**

Returns `404` with `{ "error": "not_found", … }` when the asset id or the distribution id is unknown.

<CalloutBox variant="tip" title="Payment-token units and conversion">
`total_amount` and `distributed` are measured in the **payment token's** base units, not the asset token's. Classic Stellar assets (SACs) such as USDC use 7 decimals, whereas other tokens may specify different decimals.

```typescript
// Converting distribution amounts for a payment token with 7 decimals (e.g. SAC USDC):
const paymentDecimals = 7;

// Pool size:
const rawTotal = BigInt(distribution.total_amount); // "100000000000"
const displayTotal = Number(rawTotal) / (10 ** paymentDecimals);
// => 10,000.0 USDC

// Claimed so far:
const rawDistributed = BigInt(distribution.distributed); // "25000000000"
const displayDistributed = Number(rawDistributed) / (10 ** paymentDecimals);
// => 2,500.0 USDC
```
</CalloutBox>
